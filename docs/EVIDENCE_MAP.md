# Evidence-to-output map

This map uses semantic LaTeX labels and source filenames, not page or figure numbers that can change after typesetting. Paper anchors were read from the latest delivered-author-source copy (`sections/results.tex`, `sections/rtx_confirmation.tex`, `sections/supplement.tex`, and relevant table sources). The statistics source map additionally binds its source archive and estimator origins. This is a mapping of computed evidence, not a claim of pixel-identical figure regeneration.

All JSON paths below refer to `reproduce/results/recomputed.json`.

## Not mapped as reproduced

- `fig:constraints` and `fig:construction`: mechanism diagrams and full numerical-agreement records are not reconstructed by these scalar statistics.
- `fig:local`: original two-repeat LOCAL transactions are not the same experiment as the later 12-block A5000 confirmation.
- Complete phase decomposition, all table formatting and all graphics require the separately audited figure-generation package.
- P4 recovered source is not the LOCAL frontend and cannot substitute for its implementation or qualification records.

## Publication integration requirements

Before release, add a machine-readable table of these semantic anchors, the final public source filenames and the exact release hashes. When figures are added, generate their numeric inputs from the same reconstruction output or explicitly identify separately bound inputs; compare rendered values with the frozen manuscript. Never infer uncomputed confidence intervals from point-estimate equality.
