# Editable scientific figures
Run `python3 scripts/rebuild.py` from any directory with dependencies in requirements.txt installed. Python -O/-OO are rejected. Outputs comprise eight formal and three alternative PDF/SVG pairs and 27 native TeX tables.

This public-review derivative uses allowlisted statistical fields. Original native identities, prompt hashes, backend identities, host timestamps and source receipts from the three native CSV tables are not provided. RTX per-row labels are newly assigned public IDs; they are not original request identities. See ../DATA_MINIMIZATION.json. Frozen derived input hashes are verified before drawing. Numerical values and row order are unchanged.

No original raw audit directory is included, and no raw-request audit is promised by this figure entry point. The figure pipeline rechecks frozen saved-value, pairing and visual encoding consistency. It does not rerun GPU/model experiments.

DejaVu font licensing is retained in typography/LICENSE_DEJAVU. Author-owned text, figures and data use CC BY 4.0; original scripts use MIT, subject to third-party exceptions in ../../LICENSE.md. Manuscript links retain their historical values and may point to a private repository.
